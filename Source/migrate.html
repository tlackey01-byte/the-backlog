The Backlog — one-time state migration

Paste the raw values of the 5 backlog-*-v1 localStorage keys from the live claude.ai artifact (open its devtools Console on that tab and run the snippet at the bottom of this page, or call localStorage.getItem('backlog-owned-v1') etc. one at a time). Leave a field blank if that key was never set. Then sign in with the same Firebase account the new site uses and click the button. This writes the assembled state once to users/<uid>/state/games — safe to re-run, it always overwrites with whatever is currently in these fields.

Snippet to run in the live artifact's devtools Console to grab all 5 values at once:

['backlog-owned-v1','backlog-progress-v1','backlog-played-v1','backlog-platforms-v1','backlog-deleted-v1'].forEach(k => console.log(k, '=>', localStorage.getItem(k)))
